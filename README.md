# Hydra Boss Manager

A simple and intuitive tool designed to help manage **Hydra boss runs in Metin2**.

## Features

- ⏱️ **Cooldown Alarm** — Configure an alarm to notify you when the Hydra cooldown is over.
- 📦 **Chest Tracking** — Record how many chests were obtained from each run.
- ✅ **Run Status** — Register each run as:
  - Successful
  - Failed
  - Bugged
- 💰 **Profit Calculation** — Calculate your current profit based on the number of chests obtained and the cost of the passes used.
- ⏲️ **Dungeon Metin Timer** — Start a timer for the dungeon's Metin, useful for a tactic that can save time when a run is not going well.
- 🐉 **Dual Hydra Management** — Manage up to **two Hydra runs simultaneously**.

## About

Hydra Boss Manager was created to make Hydra farming easier to track and manage, providing the most useful information in a simple and easy-to-use interface.
